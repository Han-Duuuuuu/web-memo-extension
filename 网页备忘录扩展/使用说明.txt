网页备忘录 1.5.0 — 文字与附件列表存 D 盘 / 真实文件拖出 / GPT 页面兼容
适用：Windows 10 / 11 + Microsoft Edge + Windows 自带 .NET Framework 4.5 及以上

这版的使用方式
1. 在目标网页（如 PubMed、GPT）右键，选择“在此页记备忘录”。
2. 将文件、文件夹或 ZIP 从资源管理器拖到备忘录虚线区域。
3. 本地接收框出现后，将鼠标保持在接收框内，再松开鼠标。也可先点击虚线区域打开接收框，再拖入。
4. 拖入 ZIP 后自动解压，并在备忘录里显示第一层文件和文件夹；子文件夹点“展开”继续查看。
5. 点击文件名称直接用系统默认软件打开；点击文件夹名称在资源管理器中打开。

从备忘录拖出真实文件
1. 按住附件名称并拖动，保持按住鼠标，待助手准备好文件拖放后，拖到目标窗口再松开。单击名称仍然打开文件。
2. 也可点附件下方的“拖出”，在出现的本地窗口中按住文件名称，拖到目标窗口再松开；这是操作较慢或直接拖出未成功时的备用入口。
3. 可以拖到接收文件的网页上传区（例如 GPT 的输入/上传区域）、资源管理器或其他应用。目标网页对类型、大小和文件夹的限制仍然适用。
4. 拖动过程中按 Esc 可取消；本地窗口可关闭，等待 90 秒未完成也会关闭。助手启动前如果鼠标已经松开，会提示重新拖动。
5. 拖出只允许复制，不移动原文件，不移除便签关联。拖出 ZIP 行得到原 ZIP；展开 ZIP 后拖出子文件得到解压后的文件。
6. 拖出时可以悬停切换到其他标签页；来源页关闭或导航会取消。每次拖出一个项目，文件夹是否能拖入网页取决于目标网站。
7. 文件由 Windows 以真实文件格式交给目标窗口，不是路径文字或 file:// 链接。扩展自身不上传；你主动拖到网站上传区后，由目标网站处理上传。

GPT 页面拖入修复
文件拖到备忘录区域时，扩展在页面加载初期的捕获阶段先处理，避免网页自身的全局上传/拖放监听拦住事件；备忘录外的拖放仍交给网页。
升级后务必刷新 GPT 页面，让新的 document_start 监听生效。更新扩展后仍停留在原页面，旧脚本不会自动替换。
拖入仍须保持按住，等本地接收框出现后再松开；如果松开过快，点虚线区域先打开接收框，再重新拖入。也可使用“添加文件/文件夹”。

为什么会出现本地接收框
Edge 网页不会把拖入文件的完整磁盘路径交给脚本。本版使用本地助手的 Windows 拖放接收框取得真实位置，才能打开和改名电脑上的原文件。
拖到备忘录时会自动呼出接收框，无须经过“添加文件”的文件选择窗口。若松开太快，文件可能还没交给接收框，请重新拖一次。
接收框可关闭取消；切换标签页或关闭备忘录会取消待接收状态，90秒未完成也会自动关闭。

更新（已有便签不要卸载扩展）
1. 先备份重要便签。解压新包，把“网页备忘录扩展”里的文件覆盖到以前加载扩展的同一个文件夹。
2. Edge 打开 edge://extensions/ ，点击扩展的“重新加载”，确认版本为 1.5.0，刷新所有需要使用的网页（包括 GPT 页面）。
3. 打开备忘录底部的“本地文件设置”，复制扩展 ID。
4. 双击新包“本地文件助手”文件夹中的 Install.cmd，粘贴 ID 并回车。即使之前装过助手，也需要重新运行本次的新安装脚本。程序和解压副本已改到 D:\网页备忘录助手 与 D:\网页备忘录数据（D 盘不可用时自动改用 E 盘）；脚本会自动把以前留在 C 盘的记录和解压副本搬过去，并改写登记路径，已关联的文献不会失效。
5. 出现 Installation complete 后，回设置页点“检查连接”。助手版本和功能检查通过即可使用。
首次安装：开启开发人员模式，点击“加载解压缩的扩展”，选择含 manifest.json 的“网页备忘录扩展”文件夹。
安装脚本会先在临时测试文件上自检 ZIP、中文路径和改名，通过后再安装，不修改你的文献或现有登记。
助手按需启动，没有常驻网络服务；通常不用管理员权限、不用 Python。建议正常双击安装，不必以管理员身份运行。
本版助手仍为 C#，无需 Python；不使用已废弃的 host\wbmemo_host.py。

快速改名
• 在项目下点“改名”，输入新名称，按回车或点“确定改名”。Esc 或“取消”退出。
• 普通文件或文件夹：修改磁盘上的原名称，同时更新已保存的关联。
• 文件扩展名保持不变，例如 PDF 的改名输入框只需要填写名称，不用填写 .pdf。
• 文件夹改名后，已经登记的子文件路径和其他文献便签中的相应关联也会更新。
• 压缩包内部项目：修改的是解压后的副本，不会修改原 ZIP 内容，也不需要重新压缩才能打开。
• 重名或无效名称会提示错误，不覆盖已有文件。

ZIP 展开与保存
• 自动解压目前支持普通、非加密 .zip；RAR / 7z 可先手动解压再拖入文件夹，或作为普通文件关联并用已有解压软件打开。
• 原 ZIP 保留原位，解压后的文件保存在 D:\网页备忘录数据\Extracted 下（D 盘不可用时自动改用 E 盘），不是临时预览；重开网页后仍可使用。
• 点 ZIP 行的“打开解压目录”可直接进入解压后的目录；“定位”选中原 ZIP。
• 一个目录一次显示100项，更多项目点“加载更多”。ZIP 最多自动处理5000项、解压后总计2GB，超出时请手动解压后关联文件夹。
• 移除关联不删除原文件、原 ZIP 或解压副本。需要释放解压副本占用的磁盘空间时，可先“打开解压目录”，确认后自行删除不再需要的内容。
• 同一 ZIP 再次拖入会复用已有解压副本，保留你对副本做的改动；如果原 ZIP 内容变更，请先手动解压到新文件夹，再关联新文件夹。

其他说明
• 每个完整网址的文字和关联列表独立保存；问号后的参数不同也会分开，#片段不区分。
• 文字和附件列表保存在 D:\网页备忘录数据\Memos；扩展自身不会上传文件。卸载扩展不会清除已经迁移的 D 盘记录，但旧版尚未迁移的浏览器记录仍可能丢失。移动扩展文件夹可能改变扩展 ID，需要重新安装助手。
• 备忘录里的“移除”只解除关联；“清空文字”只清空文字。
• 助手登记文件位于 D:\网页备忘录数据\links.json（程序本体在 D:\网页备忘录助手）。备份时请同时保留扩展数据与这两个目录（含解压副本）。
• 在资源管理器外部移动或改名后，需要重新关联；通过备忘录改名会自动更新已登记路径。
• Edge 内置页、扩展商店及内置 PDF 阅读器等页面无法显示浮窗。请在允许注入扩展的普通网页使用。

1.5.0 存储更新
笔记文字和附件列表均经 native messaging 保存到 D:\网页备忘录数据\Memos，每个网址的文字和附件列表分别为 JSON 文件，文件名使用存储键的 SHA-256。旧记录在设置页检查连接或首次打开任意备忘录时自动逐条迁移；写入成功才移除浏览器记录。磁盘已存在同键记录时保留磁盘版本。迁移中断可重试。
保存通过临时文件、刷盘和原子替换完成；上一版本保存在同目录的 .bak 文件。D 盘不可用、空间不足、权限不足或助手未安装时明确提示失败，不在浏览器中另存一份。读取失败会禁用编辑，避免空内容覆盖原记录。
单条文字或附件列表的 JSON 上限约 680 KB，超出会提示失败并保留原记录。大量附件可分到不同网页备忘录。
助手程序、原始附件位置不变。备份请保留整个 D:\网页备忘录数据 目录，包含 Memos、links.json 和 Extracted。Edge 本身及扩展程序仍可能位于 C 盘，此设置不迁移整个浏览器。
Windows 本机实际安装和拖放仍需确认；已在 Linux/Mono 使用真实 C# 存储处理程序验证迁移、重试、重开读取、失败保留和改名同步，并完成 Chromium 脚本回归测试。
