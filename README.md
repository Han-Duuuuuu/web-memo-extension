# 网页备忘录扩展

适用于 Windows 10/11 和 Microsoft Edge 的网页备忘录扩展。支持按网页保存笔记、关联本地文件和文件夹、拖入和拖出附件、快速改名，以及 ZIP 自动解压与目录展开。

## 下载 1.5.0

[下载完整源码包 ZIP](downloads/web-memo-extension-1.5.0.zip?raw=true)

下载后解压，扩展入口是 `网页备忘录扩展/manifest.json`。仓库中的 `网页备忘录扩展` 文件夹也包含完整源码。

## 安装或更新

1. 首次使用：Edge 打开 `edge://extensions/`，开启开发人员模式，选择“加载解压缩的扩展”，加载包含 `manifest.json` 的“网页备忘录扩展”文件夹。
2. 已有用户：先备份数据，把新文件覆盖到原来加载扩展的同一文件夹，然后点击“重新加载”。不要卸载扩展，以免尚未迁移的旧笔记丢失。
3. 在扩展管理页复制当前扩展 ID。双击 `本地文件助手/Install.cmd`，粘贴 ID，等待 `Installation complete`。更新用户也需要重新运行本次安装脚本。
4. 保存并关闭旧版备忘录，刷新所有目标网页。打开“本地文件设置”，点击“检查连接”，确认助手为 1.5.0，并完成旧数据迁移。首次打开备忘录也会启动迁移。

本地助手使用 C# 和 Windows 自带的 .NET Framework 编译运行，不需要 Python。文字和附件功能均需要本地助手。

## 数据保存位置

- 助手程序：`D:\网页备忘录助手`
- 备忘录文字和附件列表：`D:\网页备忘录数据\Memos`
- 附件位置登记：`D:\网页备忘录数据\links.json`
- ZIP 解压副本：`D:\网页备忘录数据\Extracted`

原始附件留在原来的位置。移除关联不会删除原文件。备份时请保留整个 `D:\网页备忘录数据` 目录。

1.5.0 会逐条迁移旧版保存在浏览器中的笔记和附件列表；确认磁盘写入成功后才移除对应旧记录。磁盘已有同键记录时以磁盘版本为准，中断后可以重试。备忘录保存失败会显示错误，不自动回退保存到 C 盘。单条文字或附件列表的 JSON 上限约 680 KB。

Edge 程序及其其他浏览器数据仍可能位于 C 盘，这个扩展不会迁移整个浏览器。

## 文件拖放

- 拖入：将文件、文件夹或 ZIP 拖到备忘录，保持按住鼠标，等本地接收框出现后再松开。也可先点击虚线区域打开接收框，再拖入文件。
- 拖出：按住附件名称拖动，保持按住鼠标，待助手准备完成后拖到目标窗口再松开。备用方式是点击附件下方的“拖出”，从本地窗口中的名称拖动。
- 单击附件名称仍然打开文件。拖出只允许复制，不移动原文件；ZIP 行拖出原 ZIP，展开后的子文件拖出解压副本。
- 目标网站或应用决定是否接收文件、文件夹及允许的类型和大小。扩展自身不上传文件内容；主动拖到网站上传区域后，由目标网站处理上传。

内容脚本使用关闭的 Shadow DOM 隔离样式，并在页面加载初期捕获备忘录区域内的文件拖放事件，避免网页全局拖放监听拦截。更新后需要刷新网页才能启用新逻辑。

## 验证情况

JavaScript 语法检查、Chromium 中的内容脚本回归测试，以及 Linux/Mono 上的 C# 5 编译和存储测试已通过。测试覆盖旧数据迁移、写入失败重试、进程重启后读取、附件改名同步，以及 ZIP 和 FileDrop 数据自检。

浏览器回归测试模拟了扩展 API 和本地助手响应；Windows Edge 与本地助手的端到端安装、实际 OLE 鼠标拖放及 GPT 网站接收上传尚需在 Windows 上确认。安装脚本会在本机再次编译并运行自检。

更多说明见扩展目录中的 `使用说明.txt` 和 `更新说明_1.5.0.txt`。
